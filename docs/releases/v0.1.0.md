# ReproCrate v0.1.0 — pre-release

This is an **experimental CLI-only milestone**, not the stable v1.0.0 release.

## Features

- Explicit command execution without an implicit shell.
- Output retention caps per stream, timeout/exit status and high-level environment metadata.
- Local JSON/Markdown reports using versioned schema 1.0.0.
- Basic redaction of common secret formats and inert JSON report inspection.
- Initial Rust integration tests and documentation.

## Usage

```text
reprocrate doctor
reprocrate capture --output failure.json --markdown failure.md -- cargo test
reprocrate inspect failure.json
```

Capture executes the command on your actual host. It **is not a sandbox**. Generated reports may still contain secrets and private information. **Review complete exports before sharing.**

## Known limitations

No desktop app, safe ZIP bundles, full process-tree termination, comprehensive redaction, comparison engine, signed installers, notarization, or guarantee of bug reproducibility. stderr/stdout are converted using lossy UTF-8 and truncated at configured limits. `inspect` accepts only the current schema version and at most 4 MiB. License compatibility of third-party components is under ongoing review; third parties retain their licenses.

## Install

Download the archive matching the release's actual platform/architecture, extract, and run `reprocrate --help`. There are no elevated installers or automatic network access. Platform checksums accompany each archive as `.sha256`. You can also build from source with stable Rust 1.82+ using `cargo build --release -p reprocrate-cli --locked`.
