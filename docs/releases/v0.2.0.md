# ReproCrate v0.2.0 — experimental CLI pre-release

This release extends the original Rust CLI; it is **not** stable v1.0.0.

## Changes

- New inert `reprocrate analyze` command for bounded textual log imports, including stdin (`-`), JSON export and readable Markdown output.
- Generic heuristics plus initial Cargo, pytest, Jest and Vitest log format recognition. These are preliminary adapters, not complete parsers of every framework's output.
- Stable deterministic, non-cryptographic FNV-1a 64-bit failure fingerprints with conservative grouping and occurrence counts.
- Captured JSON/Markdown reports now include optional sanitized failure observations without changing the existing report schema version; old reports can still be inspected.
- Fixed input bounds, truncation indicators, no-overwrite output behavior, and regression fixtures for the four named frameworks.

## Example

```text
reprocrate analyze build.log --output findings.json --markdown findings.md
reprocrate capture --output failure.json -- cargo test
reprocrate inspect failure.json
```

## Privacy and security

Local-first; no implicit shell or network upload. Command capture is **not sandboxed**; log import never executes the log. Redaction is best-effort, not a guarantee; inspect the full export before sharing. Fingerprints are grouping aids, not cryptographic integrity hashes or proven root causes.

## Known omissions

No desktop GUI, JUnit XML parser, fully featured test adapters, report comparison, portable bundles, automated reproduction, controlled process-tree cancellation, code signing or installers. Dependency-license review and security hardening are ongoing.

Packages are portable CLI archives for the platforms actually built by release CI, accompanied by `.sha256` files. Do not assume the release exists until GitHub marks it published.
