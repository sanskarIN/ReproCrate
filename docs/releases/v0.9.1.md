# ReproCrate v0.9.1 — ZIP security advisory maintenance (experimental pre-release)

> **Release candidate; not published until the v0.9.1 gated workflow completes successfully.** Do not infer published assets from this document.

## Why this update exists

The October 19, 2026 scheduled dependency check failed on the CLI/core `Cargo.lock`: it found `zip` 2.6.1 affected by **RUSTSEC-2026-0367**, **RUSTSEC-2026-0368** and **RUSTSEC-2026-0369**. RustSec specifies a patched range of **zip 9.0.0 or newer**. ReproCrate currently reads ZIP members individually and writes verified fixed member paths without calling the vulnerable upstream bulk-extraction helpers. Nevertheless a vulnerable dependency should be replaced rather than silently ignored.

## Changes

- Pin `zip` **9.0.5** with only the `deflate` feature and update both independently locked Rust workspaces to the fixed version.
- Raise shared Rust MSRV from **1.82** to **1.88**, required by zip 9.x, while preserving the report and bundle schemas.
- Bump the CLI/core workspace and Tauri/desktop/npm package and lockfile metadata to **0.9.1**.
- Add automated tests that refuse a reverted vulnerable ZIP lockfile or an inconsistent package version across independently locked workspaces.
- Add advisory gates to the release validator for **both** Rust lockfiles (`cargo-audit`) and the desktop npm lockfile (`npm audit --audit-level=high`).
- Retain three-platform native CLI smoke tests, actual CLI and desktop binary builds, local archive SHA-256 self-verification, and the strict **12-asset** draft release publication gate from v0.9.0.

## Limitations

ReproCrate remains a **developer pre-release**: no sandbox for user-selected commands, guaranteed secret removal, signed installers/notarization, verified clean-machine desktop GUI/accessibility testing, or stable-release certification. A matching checksum does **not** authenticate a publisher. Existing v0.9.0 published binaries were built before this security maintenance and must not be advertised as patched.
