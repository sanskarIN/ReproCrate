# ReproCrate v0.5.0 — desktop foundation developer pre-release

**Status:** Candidate until GitHub release publication is confirmed; **not stable v1.0.0**.

This milestone adds a native-desktop **Tauri 2 / React** foundation over the Rust core, keeping the previous Rust CLI working.

### Desktop workflows

- Native report inspection with bounded, inert import.
- Privacy-preserving structural comparison of existing reports.
- Heuristic log inspection of a bounded local file.
- Non-executable reproduction checklist generation.
- Local privacy-review preview with optional exclusions and manual literal masks.
- New-file-only reviewed JSON export; existing files are never replaced deliberately.
- A responsive desktop workspace with explicit read-only mode in a normal browser.

### Build and security model

Desktop frontend and Rust platform checks live in GitHub Actions. Npm dependencies and the separate Tauri Rust workspace are locked; native app icons are generated from a repository-owned SVG. No filesystem or shell plugins, remote URLs, telemetry, authentication, or automatic uploads are requested by the desktop bridge.

The original CLI continues to be tested independently on Linux, macOS and Windows. Review inputs before sharing. Best-effort redaction may miss sensitive content; structural comparison and recipe steps do not prove a bug was reproduced. The first desktop bridge does not support executing commands from imported files.

### Known limitations

This is a desktop *foundation*. No claim is made of signed installers, automatic updater, GUI-assisted file picker, database history, complete cross-platform visual testing, safe host sandbox, or stable release. Platform-specific native binary availability is determined by completed release artifacts, not inferred from source code.
