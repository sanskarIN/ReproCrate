# ReproCrate v0.6.0 — local report history developer pre-release

**Published experimental pre-release:** https://github.com/sanskarIN/ReproCrate/releases/tag/v0.6.0 (October 17, 2026). **Not stable v1.0.0.**

**Verified build and publication:** https://github.com/sanskarIN/ReproCrate/actions/runs/39046224080. All six Linux, Windows and macOS CLI/desktop build-upload jobs and gated publication succeeded. The GitHub Releases API confirms six executable archives plus six individual SHA-256 files.

This milestone builds on v0.5.0's Tauri 2 + React desktop. The existing Rust CLI, secure diagnostic bundles and privacy-conscious report comparisons remain available.

## New capability

- **Explicit report indexing:** opt-in local SQLite database for selected, schema-validated report paths and limited metadata.
- **Search:** case-insensitive title/OS/architecture query with SQL parameters, strict query and result caps.
- **Inspect from history:** opens the selected original path via the previous read-only inspector.
- **Forget index:** deletes the SQLite row only, not the original diagnostic report. Re-indexing updates the row without creating a duplicate.
- **Privacy:** no automatic indexing, raw logs, raw command arguments, credentials, uploads, accounts or imported-command execution through this feature.
- **Cross-platform validation:** isolated database tests, React production build, native desktop IPC and full executable builds passed on Windows/Linux/macOS before publication.

## Important limits

Local SQLite metadata includes complete file paths, which may themselves contain sensitive information. Titles and identifiers receive only best-effort sanitization; data deletion cannot guarantee erasure from snapshots and backups. The desktop currently accepts manually entered paths rather than a native picker and unsigned executables are developer previews, not signed installers.
