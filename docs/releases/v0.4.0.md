# ReproCrate v0.4.0 — experimental CLI pre-release

This version builds on published v0.3.0's review tools and integrity-checked diagnostic bundles.

## Features

- `reprocrate compare baseline.json candidate.json --output comparison.json [--markdown comparison.md]`: deterministic privacy-minimizing structural report comparison, explicit redacted/missing/incomplete states and heuristic fingerprint differences where both analyses are complete.
- `reprocrate recipe create --report reviewed.json --output recipe.json [--markdown recipe.md]`: versioned, inert manual reproduction guide without command details by default.
- Optional command reference requires `--include-command --acknowledge-reviewed`; reviewed fields receive best-effort masking and still require manual verification.
- `reprocrate recipe inspect recipe.json`: bounded inert schema and step validation.
- Rust unit and CLI integration coverage for field changes, suppressed raw values, redacted/truncated unknowns, recipe opt-in, non-executability and no-overwrite behavior.
- Continued Windows/Linux/macOS CI and guarded release archive/checksum publishing.

## Limitations

ReproCrate never executes imported recipes or automatically uploads diagnostics. Structural comparison does not prove a root cause, while fingerprint grouping can collide. Best-effort redaction is not proof of confidentiality. Command capture remains unsandboxed. The desktop GUI, report history and stable v1.0.0 are future milestones.

See [report comparisons](../reference/report-comparison.md) and [reproduction recipes](../reference/reproduction-recipes.md).
