Developer pre-release: available binaries are unsigned and are not certified installers. Running selected commands is not sandboxed.

DESIGNED FOR LOCAL CONTROL

Diagnostics without background uploading

01 / CAPTURE

Explicit process capture

Run only the program you choose; record bounded output, exit status and environment basics. Execution is not isolated.

02 / COMPARE

Structural report diffs

Compare observations while omitting changed raw command arguments and log values from exported differences.

03 / REVIEW

Privacy and offline issues

Manually exclude sensitive fields and prepare GitHub, GitLab, Gitea or generic Markdown issue drafts without posting.

04 / HISTORY

Opt-in desktop history

Search only reports you explicitly index in a local SQLite database. Paths and metadata can still be sensitive.

PLATFORM BUILDS

Unsigned Windows, Linux and macOS previews

GitHub Releases provides Windows x86-64 ZIP, Linux x86-64 tar.gz and macOS ARM64 tar.gz archives for both CLI and desktop, along with SHA-256 sidecars. Binaries are not signed installers and system runtime prerequisites may apply.

Choose the latest published release ↗

$ reprocrate verify-download ./reprocrate-v0.8.0-linux-x86_64.tar.gz \

--checksum ./reprocrate-v0.8.0-linux-x86_64.tar.gz.sha256

The checksum command is available starting with v0.8.0. Hash equality only detects a mismatch against the sidecar you obtained; it does not prove that the publisher or archive is trustworthy.
